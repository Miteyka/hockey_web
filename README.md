# hockey_web

Python 3.10+. Внешние пакеты не требуются. В терминале папки проекта:

```sh
python app.py
```

Откройте http://127.0.0.1:8000. Выберите «Тренер», пароль `demo123`. База hockey.sqlite3 создаётся рядом с app.py, сохраняется между запусками. Пользовательские сеансы сбрасываются при перезапуске. Порт 8000 должен быть свободен.

## Демонстрация
1. Войти тренером и создать черновик на выбранную дату.
2. Задать минуты четырёх блоков, окно занятия и участников. Утвердить план. Превышение окна отклоняется.
3. Начать занятие. Заполнить факт и посещаемость, закрыть занятие.
4. Открыть аналитику, выбрать период, содержащий дату занятия. Проверить план/факт, полноту, посещаемость, отклонения.
5. В песочнице увеличить технические упражнения с 25 до 35 минут: появляется превышение на 10 минут и обновляются полосы долей времени.

Для неизвестного факта выбрать «Нет данных», очистить минуты, указать причину. Невыполнение обозначается статусом «Не выполнено» и 0 минут. Пропуск и 0 учитываются по-разному.


## Файлы
app.py — веб-слой, формы, объекты плана и песочница.
core.py — сервисы и SQLite-репозиторий.
test_core.py — проверки предметных алгоритмов.
test_web.py — проверки полного веб-сценария через WSGI и защиты форм.

```sh
python -m unittest -v
```

Проверено 14 тестов. Полный сценарий WSGI: вход → создание → утверждение → начало → закрытие → аналитика → песочница. Браузерную визуальную проверку в среде подготовки выполнить не удалось: запуск Chromium запрещён ограничением socket().

## Границы учебного прототипа
Это локальный прототип ядра. Сервер слушает только 127.0.0.1. Вход демонстрационный: общий пароль и выбор роли; не применять для реальных данных или публичного размещения. Пароль можно заменить переменной окружения HOCKEY_PASSWORD.

Фиксированы одна команда, три обезличенных игрока и четыре блока упражнений. Администратор может просматривать состав, но не редактирует результаты. Управление пользователями, редактирование каталога и состава, отмена занятия и исправление закрытого факта — следующие этапы. Веб-формы вводят минуты; дополнительные объёмы и внеплановые записи поддерживаются ядром, но не формами. Песочница сравнивает учебный план и не сохраняет его, как указано в приложенном готовом документе. Полноценная производительность N3 и восстановление резервных копий пока не испытаны.
